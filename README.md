# MVC-PW

## Sobre o projeto

Atividade acadêmica de programação web em C#, organizada em controladores, modelos e telas Razor. Inclui exemplos relacionados a carros, celulares e eventos.

## Como explorar

Abra `MVC-PW.sln` no Visual Studio e confira se o projeto referenciado pela solução está disponível. A árvore atual contém arquivos C# e Razor, mas não apresenta um arquivo `.csproj`.
